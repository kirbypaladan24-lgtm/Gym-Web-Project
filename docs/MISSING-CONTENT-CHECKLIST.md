# Missing Content Checklist — for the AV Fitness Gym owner

Everything the website needs from the gym before it can publish real facts.
Nothing below is blocking development — the site ships with clearly marked
placeholders until each item arrives. Please confirm each item with the
branch it belongs to; do not approximate.

## Branch details (per branch)

- [ ] Official branch name (as it should appear publicly)
- [ ] Full verified street address
- [ ] Map coordinates or a Google Maps link you approve
- [ ] Operating hours — weekdays / weekends
- [ ] Holiday and temporary-closure procedure (who announces, how far ahead)
- [ ] Branch contact number and/or desk email (public-safe)
- [ ] Branch photographs: exterior, entrance, reception, training floor (approved for publication)

## Equipment & facilities (per branch)

- [ ] Verified equipment inventory (names, counts)
- [ ] Category per item (cardio / strength / free weights / functional)
- [ ] 1–3 approved photographs per equipment zone
- [ ] Anything temporarily unavailable and how to mark it

## Memberships

- [ ] Every plan: name, exact price (PHP), duration, inclusions
- [ ] Branch eligibility per plan (both branches? one?)
- [ ] New-member registration requirements (ID, age, waiver…)
- [ ] Renewal rules — manual renewal or automatic recurring billing?
- [ ] Cancellation, refund, suspension, and expiry policies
- [ ] Any transferability between branches

## Payments

- [ ] Accepted methods (GCash, Maya, bank transfer, QR, card, gateway…)
- [ ] Whether a merchant/business account and API checkout exist
- [ ] One-time per term or recurring?
- [ ] How staff verify payments today (screenshots? provider dashboard?)
- [ ] Receipt and refund procedure

## 360° virtual tour

- [ ] Do 360° panoramas already exist? If yes, the files.
- [ ] Permission to photograph both branches
- [ ] Approved viewpoints per branch (entrance, floor, cardio, others?)
- [ ] Areas/people that must NOT appear (privacy)

## Staff & operations

- [ ] Owner/admin account holder (name + email)
- [ ] Branch manager per branch (who updates what)
- [ ] Which actions each role may perform
- [ ] Who maintains prices, updates, and equipment records after launch

## Brand & content

- [ ] Higher-resolution logo files if available (current emblem: 960×960 JPG)
- [ ] Approved "About" story text (founding, approach, values)
- [ ] Official social media links
- [ ] Privacy notice review + membership terms review (legal sign-off)
- [ ] Grand-opening promotions or launch announcements, if any
